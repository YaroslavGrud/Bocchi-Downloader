# 🎸 Bocchi Downloader (BocchiStation)

Персональный Telegram-бот для скачивания музыки из Яндекс Музыки в высоком качестве, оптимизированный для работы на **Raspberry Pi**. 

Проект вдохновлен персонажем Хитори Гото (Bocchi-chan) и обладает уникальным характером в сообщениях и мониторинге системы.

---

## ✨ Основные возможности

* **HQ Качество:** Загрузка треков в лучшем доступном качестве (320kbps / M4A).
* **Автоматические теги:** Бот ищет обложки 1000x1000 в iTunes, подтягивает тексты песен (LRC) и заполняет все ID3-метаданные.
* **Анти-мусор:** Автоматическая очистка комментариев и рекламных ссылок, вшитых в файлы.
* **Облачная загрузка:** Если файл больше 50 МБ (лимит Telegram), бот автоматически загрузит его на Catbox.moe и даст прямую ссылку.
* **Живой мониторинг:** Команда `/status` показывает состояние Raspberry Pi (CPU, RAM, Температура, Сеть) через призму мыслей Хитори.
* **Очередь загрузки:** Поддержка семафоров для управления нагрузкой на слабом железе.

---

## 🛠 Технологии

* **Язык:** Python 3.10+
* **Библиотеки:** `python-telegram-bot`, `yandex-music-api`, `mutagen`, `syncedlyrics`.
* **Железо:** Протестировано на Raspberry Pi (поддержка мониторинга температуры и сети).
* **Сетевой стек:** Поддержка проксирования через v2RayA.

## 🚀 Быстрый старт

### 1. Подготовка
Склонируйте репозиторий и установите зависимости:
bash
git clone https://github.com/YaroslavGrud/Bocchi-Downloader.git
cd Bocchi-Downloader
pip install -r requirements.txt


### 2. Настройка
Создайте файл `.env` в корневой папке и добавьте свой токен:
env
TELEGRAM_TOKEN=ваш_токен_бота
DOWNLOADER_PATH=/путь/к/yandex-music-downloader


### 3. Запуск
bash
python main.py

## 🌸 Персона (Character)

Бот общается в стиле **Хитори Гото** из "Bocchi the Rock!". Модуль мониторинга системы (`/status`) стилизован под "Секретный блокнот", где бот переживает о нагрузке на систему и температуре процессора так же, как Хитори переживает в социальных ситуациях.
